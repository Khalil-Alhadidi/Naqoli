## Runtime and libraries

- .NET 10 SDK and ASP.NET Core 10.
- xunit.v3 4.0.2 (test framework; runs on Microsoft Testing Platform, opted in through global.json).
- xunit.runner.visualstudio 4.0.1 (xUnit adapter for IDE test explorers).
- Microsoft.NET.Test.Sdk 18.11.0 (test host for IDE test explorers).
- Microsoft.Playwright 1.63.0 (screen journeys).
- Microsoft.AspNetCore.OpenApi 10.0.12 (OpenAPI document for the mock wallet API, as generated by the .NET 10 webapi template).
- Bootstrap 5.3.3 (static CSS and JS bundled by the .NET 10 Blazor Web App template under src/Agent.Web/wwwroot/lib).
- Microsoft.EntityFrameworkCore.SqlServer 10.0.13 and Microsoft.EntityFrameworkCore.Design 10.0.13 (data access, migrations).
- System.Security.Cryptography.Pkcs 10.0.13 (direct reference that lifts the vulnerable 9.0.11 copy brought in by Microsoft.Data.SqlClient).
- SQL Server (local instance, LocalDB or container) as the mock wallet's database.
- dotnet-ef 10.0.13 (EF Core command-line tool, pinned in .config/dotnet-tools.json).
